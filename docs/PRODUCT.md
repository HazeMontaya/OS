# Product Definition

## Category

Local-First Cognitive Operating Environment.

OS is not a chatbot, launcher or Obsidian clone. It is a cognitive desktop environment where memory, knowledge, agents, tools and system activity share one state model.

## Product invariant

**Everything OS knows, uses or does can have a visible representation.**

## Commercial differentiator

Cognitive activity itself becomes the interface:

- memory recall is visible
- graph traversal is visible
- agent/tool execution is visible
- contradictions are visible
- learning and consolidation are visible
- model/system state is visible

## Experience principles

1. 3D for orientation, relationships and activity.
2. 2D for reading, editing, permissions and precise work.
3. Local-first by default; cloud is optional.
4. No hidden unrestricted agent authority.
5. No manual memory switch: relevant approved activity enters the cognitive pipeline automatically.
6. Raw provenance is preserved; derived knowledge may evolve.
7. Secrets are references, never semantic memory payloads.
