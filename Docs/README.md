# PersonalJarvis Reference Setup für OS

## Zweck

Dieses Paket richtet das offizielle PersonalJarvis-Repository ausschließlich als
Entwicklungs-/Architektur-Referenz für **OS** ein.

## Installation

1. Klone das Repository manuell nach `S:\OS\Reference\PersonalJarvis`.
2. Das Repository wird nach:
   `S:\OS\Reference\PersonalJarvis`
   geklont.
3. Die MIT-Lizenz wird zusätzlich unter:
   `S:\OS\Reference\Licenses\PersonalJarvis-MIT.txt`
   abgelegt.
4. Quellen-Metadaten werden gespeichert.
5. Der Referenzordner wird geöffnet.

## Später aktualisieren

Aktualisiere den Klon mit `git pull` im Referenzordner.

Die Referenz wird dabei absichtlich wieder auf den aktuellen Stand von
`origin/main` gesetzt. Eigene Änderungen gehören NICHT in den Referenzordner.

## Canonical upstream

https://github.com/PersonalJarvis/PersonalJarvis

## Wichtig

- Produktname bleibt **OS**.
- PersonalJarvis wird nicht automatisch als Anwendung gestartet.
- Die Referenz ist für Architektur-, Quellcode-, Test- und Implementierungsanalyse gedacht.
- Bei direkter Übernahme wesentlicher Codeanteile muss die MIT-Attribution erhalten bleiben.
