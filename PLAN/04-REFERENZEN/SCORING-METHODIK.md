# Scoring-Methodik

Die 0–10-Bewertungen sind **relative Produktreife-Einschätzungen**, keine standardisierten Benchmarks.

Bewertet werden:

1. Autonomie / Long-Horizon
2. Multi-Agent-Orchestrierung
3. Isolation / Sandbox
4. Computer Use
5. Tool-/Integrationstiefe
6. Memory / Skills
7. Model Routing
8. Observability / Review
9. UX / Control Plane
10. Reliability / Recovery
11. Security / Permissions
12. Produkt-/Release-Reife

OS wird gegen das eigene Ziel „Local-First Personal Agent Operating Environment“ bewertet, nicht nur gegen Coding-Agenten.
